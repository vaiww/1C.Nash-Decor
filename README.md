# Наш Декор

Учебный проект конфигурации на платформе **1С:Предприятие**. Репозиторий содержит выгрузку конфигурации в XML-формате для просмотра, хранения и отслеживания изменений.

## О проекте

Конфигурация «Наш Декор» предназначена для автоматизации отдельных процессов, связанных с учетом продукции и материалов, складскими операциями, производством и взаимодействием с партнерами.

Проект находится в учебном портфолио и демонстрирует работу с объектами конфигурации 1С.

## Основные разделы

В конфигурации выделены следующие подсистемы:

- Партнеры
- Продукция
- Производство
- Склад и материалы
- Сотрудники

## Объекты конфигурации

В XML-выгрузке представлены:

- **Справочники:** партнеры, поставщики, продукция, материалы, склады, сотрудники, должности и типы объектов учета.
- **Документы:** заявка, история продаж, поставка материалов, приход продукции, производство.
- **Регистры накопления:** остатки материалов, остатки продукции, продажи, производство продукции.
- **Отчеты:** материалы и продукция.
- **Перечисления:** единицы измерения, способы оплаты, статусы заявки и оплаты, тип доставки, типы партнеров и поставщиков.
- **Роли:** администратор, менеджер, мастер, партнер и поставщик.
- **Общие модули, формы и макеты печатных форм.**


## Структура репозитория

Исходные файлы конфигурации находятся в каталоге `Nash-Decor/`.

Основные каталоги:

| Каталог | Содержимое |
| --- | --- |
| `AccumulationRegisters` | Регистры накопления |
| `Catalogs` | Справочники |
| `CommonModules` | Общие модули |
| `Documents` | Документы |
| `Enums` | Перечисления |
| `DataProcessors` | Обработки |
| `Reports` | Отчеты |
| `Roles` | Роли и права доступа |
| `Subsystems` | Подсистемы |

## Технологии

- 1С:Предприятие
- Встроенный язык 1С (BSL)
- XML-выгрузка конфигурации

## Работа с проектом

Для просмотра и дальнейшей разработки конфигурации используйте **Конфигуратор 1С:Предприятия**. Каталог `Nash-Decor/` содержит файлы конфигурации, а не готовую информационную базу с пользовательскими данными.
